# anystash-site

Public support and legal pages for **AnyStash** (Apple Shortcuts companion).

## Live URLs (GitHub Pages)

After Pages is enabled on `main` from `/` (root):

- Home: https://oxgoing.github.io/anystash-site/
- Support: https://oxgoing.github.io/anystash-site/support/
- Privacy: https://oxgoing.github.io/anystash-site/privacy/

## Stack

Static HTML + CSS only. English (v1). No build step.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080/
