Concepts

How do I start an Event Session (and Live Activity) from Shortcuts?

In the Shortcuts app, add Event Session (Live Activity) from AnyStash. Set Phase to Start, pick an Event Category (for example Parking), and leave Show Live Activity On (default) if you want the Lock Screen / Dynamic Island display. Run the shortcut—the session is saved under Events even if the Island cannot appear (unless you chose a Fail-when-full policy).

You can also start from AnyStash: More → Event Session (or the Record Event sheet). Home Screen quick actions may show the shorter label Event Session.

Phase defaults to Start. For a log-only check-in style run, set Checkpoint explicitly.

To finish: run the same action with Phase → End (ends the session; linked Live Activity dismisses with it). End by Category, or pick a specific Event Session from a previous result. Open the Events tab to review what you saved.

Prefer a guided walkthrough with screenshots and importable shortcuts? See Parking example (including the parameter guide) under Examples. If nothing appears on the Lock Screen, see Troubleshooting below. Still on older (deprecated) Start/Stop Live Activity actions? Legacy Live Activity shortcuts.

What’s the difference between a Live Activity and an Event Session? How do they work together?

A Live Activity is the in-progress display on the Lock Screen and Dynamic Island (timer, title, and related status). When it ends, it leaves the Island.

An Event Session is the activity record in AnyStash—Start, optional Checkpoints, then End—so you can open it in the app while it is running and again later in history (notes, category, linked locations). The session is the primary unit for history, conflicts, and Free daily limits.

They often work together. On Event Session (Live Activity), turn Show Live Activity On (default) to request the Island while the session is created. Turn it Off for a session-only start. In Shortcuts automations, showing the Island is best-effort: if the system cannot start a Live Activity, the Event Session can still succeed (except when If Live Activity Limit Reached is Fail).

In short: the Live Activity is the system surface for “in progress”; the Event Session is the in-app record you can browse anytime—during and after. “Event” here is not a calendar appointment. For older (deprecated) Start/Stop Live Activity actions, see Legacy Live Activity shortcuts.

How is AnyStash different from Apple Calendar events or Apple Maps’ parked car?

Apple Calendar events are appointments on a schedule in the system Calendar app. Event Sessions in AnyStash are activities you start and stop—optionally with a Live Activity while they run—and a record you can open in AnyStash anytime (during and after).

Apple Maps’ parked car (the system pin) helps you find where the car is. Parking in AnyStash helps you run the parking session: a timer on the Lock Screen and Dynamic Island, clear start and end, and a record in Events—not only a pin on the map.

What’s the difference between an Event Category and a Variable Module?

An Event Category is for Events and Live Activities—the kind of activity you’re running (Parking, Focus, Meeting, Visit, Generic, or a custom category on Pro). Check In always uses the built-in Visit category.

A Variable Module is only for variables—a folder-like group such as General or Photos so Set/Get stays organized.

They solve different jobs and are not interchangeable. In Shortcuts and the app, “category” usually means Event Category; “module” means Variable Module.

What are Free daily start limits?

After a short intro period, Free includes a limited number of Event Session starts per local day. See Settings → Usage in the app for your remaining count and What Counts. Pro Lifetime has unlimited Event Session starts.

Counts as a start: Event Session Start and Checkpoint (including when Show Live Activity is On—still one start). Legacy Start Live Activity also counts once. Does not count: Event Session End; Stop Live Activity; Check In or other standalone location saves.

Ending a session or checking in never uses the Event Session start quota.

Does Free delete my history after 30 days?

No. Free can browse and search about the last 30 days. Older sessions and locations can still stay on your device—they’re just outside the Free browse window until you upgrade to Pro.

AnyStash does not auto-delete older history because you’re on Free. You can delete older data yourself in Settings if you want to free space.

How is Check In different from saving a location on a session?

Check In saves where you are as a standalone place mark under the built-in Visit category (list and map). You don’t pick another category when checking in. It does not use the Free daily start quota.

When you start or end an Event Session, you can also save the current location on that activity—using whatever category that session uses (Parking, Focus, and so on). That place belongs to the session, not to a separate check-in.

Use Check In for a simple “I was here” under Visit. Attach location to a session when the place is part of the activity you’re running.

Can I customize categories?

Built-in categories (such as Parking, Focus, Meeting, Visit, and Generic) work on Free.

Renaming, changing icon or color, and creating new categories require Pro. The edit and create controls stay visible on Free—they open the upgrade path instead of hiding the feature.

What can global variables do?

Global variables let other shortcuts Set and Get values you stash in AnyStash—text, numbers, yes/no, lists, dictionaries, and files.

Organize them with Modules. Use a key path to read or update a nested field without replacing the whole value. Browse and preview files in the app—unlike a single named memory slot in Shortcuts. See the next item for the full key path syntax.

Signed into iCloud, your data syncs across devices under your Apple ID; you can keep individual files on this device only. See Privacy for details. In the app, use More → Copy Key Path when editing a variable to avoid typing mistakes.

How is this different from Shortcuts Storage on iOS 27?

iOS 27 Shortcuts can Store / Get / Delete content between runs, including a Global Value shared across shortcuts. That’s great for simple counters, text, or lists.

AnyStash is a browsable variable library: typed values and files, modules, key paths for nested updates, and the same app as your event sessions and Live Activities. Use system Storage for a quick memory; use AnyStash when you need structure, file management, or session-related workflows.

What is the key path syntax?

A key path is the address you type in Shortcuts to find a value in AnyStash.

Rules

  • Optional module: @ModuleName. — if you skip it, AnyStash uses General.
  • Then the variable’s root name, then optional segments for list items or dictionary keys.
  • List items count from 0: shoppingList.0 or shoppingList[0] is the first item.
  • Dictionary keys: profile.city or profile["city"]. If the key is only digits, or contains . or [, use quotes: profile["0"], profile["home.city"].
  • Rare names: a literal . in a name → \.; a root name that starts with @ → \@name; inside quoted keys → \" and \\.

Examples

  • myKey — General / myKey
  • @General.myKey — same, module written out
  • @Photos.avatar — Photos / avatar
  • myList.0 or myList[0] — first list item
  • myDict.name or myDict["a.b"] — dictionary keys
  • @General.myDict["0"] — dictionary key 0 (not “first list item”)
  • \@foo.bar — root name @foo, then key bar

Prefer More → Copy Key Path in the app, then paste into Shortcuts.

Where is my data stored?

Sessions, locations, and variable metadata sync across your devices via Apple CloudKit when you’re signed into iCloud (we don’t run our own content servers).

When available, new variable files default to iCloud Drive and sync across devices; set a file (or turn off Settings → Files) to stay on this device only.

Legacy Live Activity — do my Start / Stop Live Activity shortcuts still work?

Yes. Existing shortcuts that use Start Live Activity or Stop Live Activity keep working. For new shortcuts, use Event Session (Live Activity) instead (turn Show Live Activity On for the Island, or Off for session-only).

What they do today:

  • Start Live Activity — starts an Event Session and can show the Island; returns a Live Activity ID.
  • Stop Live Activity — removes the Island and ends the linked Event Session.

Event Session — Phase blank after updating from 1.0.1 or earlier?

On AnyStash 1.0.1 and earlier, some Event Session shortcuts left Phase blank. After you update, a blank Phase uses the current default: Start—not Checkpoint. A shortcut that used to behave like a log-only check-in may now start a session.

Fix: open the shortcut and set Phase explicitly to Start, End, or Checkpoint, then save. Going forward, always pick Phase on purpose (don’t leave it blank).

Troubleshooting

Why didn’t a new Live Activity appear? (Lock Screen / Dynamic Island)

First open Events in AnyStash. From Shortcuts, a missing Island often still means the Event Session was saved—the run did not necessarily fail.

Check in order:

  1. Show Live Activity is On for that Start (default On). If Off, only the session is created—no Island is requested.
  2. System permission: iOS Settings → AnyStash → allow Live Activities. Also check Focus modes that may hide Live Activities.
  3. If Live Activity Limit Reached—iOS caps how many Live Activities one app can show at once (about five Islands; Apple’s limit, not an AnyStash quota). This setting only chooses what happens to the display when that system cap is hit; it does not end other Event Sessions:
    • Smart / End Oldest: tries to free a slot, then show yours; if that still fails, the session can remain without a new Island.
    • Elapsed Only: only frees Islands past their planned due time; if none are elapsed, you get no new Island while the session can still save.
    • Fail: does not free a slot; Start fails and no new session is created.
  4. From the app with Show Live Activity On: if Live Activities are disabled for AnyStash, Start is blocked until you enable them (unlike many Shortcuts runs, which can still save the session).
  5. Swiping the Island away only hides the display—it does not end the Event Session. To end the session, use Phase → End, or Stop Live Activity (ends session + Island).

Parameter details: Parking → Parameter guide · older Start/Stop actions: Legacy Live Activity · why an older Island disappeared: below.

Why did an older Live Activity disappear on its own?

The Lock Screen / Dynamic Island is only the display. If an older Island goes away, open Events—the linked Event Session is often still there until you explicitly End it.

Common causes:

  • Starting another session with Show Live Activity On while iOS already had about five Islands active for AnyStash (Apple’s per-app Live Activity cap). Depending on If Live Activity Limit Reached:
    • Smart or End Oldest may dismiss an older Island to free a slot for the new one.
    • Elapsed Only may dismiss only Islands past their planned due time.
    • In the app, you may have confirmed ending an older Live Activity to continue—that removes the Island, not the older Event Session.
  • You ended the Event Session (Phase → End, or End in the app)—the linked Island dismisses with it.
  • Auto Close Previous when starting in a category that already had an active session (Single Active)—the previous session ends and its Island goes away.
  • Stop Live Activity (or an automation that stops by Activity ID / category)—that ends the linked Event Session as well as the Island.
  • You dismissed the Island (swipe away). That does not end the Event Session by itself.
  • iOS may clear Live Activities after a long time or under system limits—again, check Events for the session record.

I bought Pro but features still look locked

Open AnyStash → Settings → Restore Purchases while signed into the same Apple ID used for the purchase. Pro is a one-time non-consumable purchase tied to your Apple ID — there is no separate AnyStash account.

Location permission

AnyStash only requests Location When In Use when you check in or attach the current location to a session. We do not run continuous background GPS tracking for geofencing in the current product. If you previously denied access, open AnyStash → Settings → Permissions to enable it, or turn it on in iOS Settings → AnyStash.

Notifications or Alarms for planned event sessions

Optional reminders when a planned event session is due need Notifications and/or Alarms. Manage them in AnyStash → Settings → Permissions, or in iOS Settings → AnyStash. If access was denied earlier, re-enable it there before the next planned session.

Camera and Photo Library for session photos

Camera and Photo Library access are only requested when you snap or attach photos to an Event Session, tap the camera button on a Live Activity, or save media to a file variable. If you previously denied Camera access, enable it in iOS Settings → AnyStash.
