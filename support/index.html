Concepts

How do I start a Live Activity from Shortcuts?

In the Shortcuts app, add Start Live Activity from AnyStash. Pick an Event Category (for example Parking), set the timer if you need one, leave Save as Event Session on if you want a record under Events, then run the shortcut.

You can also start from AnyStash: More → Start Live Activity.

To finish: use Stop Live Activity and/or end the Event Session. Open the Events tab to review what you saved.

If nothing appears on the Lock Screen, see Troubleshooting below.

What’s the difference between a Live Activity and an Event Session? How do they work together?

A Live Activity is the in-progress display on the Lock Screen and Dynamic Island (timer, title, and related status). When it ends, it leaves the Island.

An Event Session is the activity record in AnyStash—Start, optional Checkpoints, then End—so you can open it in the app while it is running and again later in history (notes, category, linked locations).

They often work together. When you start a Live Activity, turn Save as Event Session On (the parameter in the Start Live Activity shortcut and in-app form; On by default) to create a linked session at the same time. You will see the Island and the session under Events in the app. Turn it Off if you only want the Island display for this start. You can also record an Event Session without starting a Live Activity.

In short: the Live Activity is the system surface for “in progress”; the Event Session is the in-app record you can browse anytime—during and after. “Event” here is not a calendar appointment.

How is AnyStash different from Apple Calendar events or Apple Maps’ parked car?

Apple Calendar events are appointments on a schedule in the system Calendar app. Event Sessions in AnyStash are activities you start and stop—optionally with a Live Activity while they run—and a record you can open in AnyStash anytime (during and after).

Apple Maps’ parked car (the system pin) helps you find where the car is. Parking in AnyStash helps you run the parking session: a timer on the Lock Screen and Dynamic Island, clear start and end, and a record in Events—not only a pin on the map.

What’s the difference between an Event Category and a Variable Module?

An Event Category is for Events and Live Activities—the kind of activity you’re running (Parking, Focus, Meeting, Visit, Generic, or a custom category on Pro). Check In always uses the built-in Visit category.

A Variable Module is only for variables—a folder-like group such as General or Photos so Set/Get stays organized.

They solve different jobs and are not interchangeable. In Shortcuts and the app, “category” usually means Event Category; “module” means Variable Module.

What are Free daily start limits?

After a short intro period, Free includes a limited number of starts per local day. See Settings → Usage in the app for your remaining count. Pro Lifetime has unlimited starts.

Counts as a start: Start Live Activity; Event Start; Event Checkpoint. Does not count: End; Stop Live Activity; Check In or other standalone location saves.

If you Start Live Activity with Save as Event Session on, that still counts as one start (not two). Ending or checking in never uses the start quota.

Does Free delete my history after 30 days?

No. Free can browse and search about the last 30 days. Older sessions and locations can still stay on your device—they’re just outside the Free browse window until you upgrade to Pro.

AnyStash does not auto-delete older history because you’re on Free. You can delete older data yourself in Settings if you want to free space.

How is Check In different from saving a location on a session?

Check In saves where you are as a standalone place mark under the built-in Visit category (list and map). You don’t pick another category when checking in. It does not use the Free daily start quota.

When you start or end an Event Session, you can also save the current location on that activity—using whatever category that session uses (Parking, Focus, and so on). That place belongs to the session, not to a separate check-in.

Use Check In for a simple “I was here” under Visit. Attach location to a session when the place is part of the activity you’re running.

Can I customize categories?

Built-in categories (such as Parking, Focus, Meeting, Visit, and Generic) work on Free.

Renaming, changing icon or color, and creating new categories require Pro. The edit and create controls stay visible on Free—they open the upgrade path instead of hiding the feature.

What can global variables do?

Global variables let other shortcuts Set and Get values you stash in AnyStash—text, numbers, yes/no, lists, dictionaries, and files.

Organize them with Modules. Use a key path to read or update a nested field without replacing the whole value. See the next item for the full key path syntax.

Data stays on your device by default; optional iCloud uses your Apple ID. See Privacy for details. In the app, use More → Copy Key Path when editing a variable to avoid typing mistakes.

What is the key path syntax?

A key path is the address you type in Shortcuts to find a value in AnyStash.

Rules

  • Optional module: @ModuleName. — if you skip it, AnyStash uses General.
  • Then the variable’s root name, then optional segments for list items or dictionary keys.
  • List items count from 0: shoppingList.0 or shoppingList[0] is the first item.
  • Dictionary keys: profile.city or profile["city"]. If the key is only digits, or contains . or [, use quotes: profile["0"], profile["home.city"].
  • Rare names: a literal . in a name → \.; a root name that starts with @ → \@name; inside quoted keys → \" and \\.

Examples

  • myKey — General / myKey
  • @General.myKey — same, module written out
  • @Photos.avatar — Photos / avatar
  • myList.0 or myList[0] — first list item
  • myDict.name or myDict["a.b"] — dictionary keys
  • @General.myDict["0"] — dictionary key 0 (not “first list item”)
  • \@foo.bar — root name @foo, then key bar

Prefer More → Copy Key Path in the app, then paste into Shortcuts.

Where is my data stored?

Sessions, locations, and variables stay on your device by default. Optional iCloud Drive / CloudKit sync uses your Apple ID. See the Privacy Policy for details.

Troubleshooting

Live Activities do not appear on the Lock Screen

Open iOS Settings → AnyStash and confirm Live Activities are allowed. Also check Focus modes that may hide Live Activities. System limit: about five Live Activities per app at once.

I bought Pro but features still look locked

Open AnyStash → Settings → Restore Purchases while signed into the same Apple ID used for the purchase. Pro is a one-time non-consumable purchase tied to your Apple ID — there is no separate AnyStash account.

Location permission

AnyStash only requests Location When In Use when you check in or attach the current location to a session. We do not run continuous background GPS tracking for geofencing in the current product. If you previously denied access, open AnyStash → Settings → Permissions to enable it, or turn it on in iOS Settings → AnyStash.

Notifications or Alarms for timed Live Activities

Optional reminders when a timed Live Activity ends need Notifications and/or Alarms. Manage them in AnyStash → Settings → Permissions, or in iOS Settings → AnyStash. If access was denied earlier, re-enable it there before the next timed session.
